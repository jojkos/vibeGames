# Project creation order

`createdAt` in `games.js` is the earliest recorded project evidence available
in Git, rather than the date a project was most recently added to this portal.
All timestamps are normalized to UTC. Remakes keep the original project's date;
Pug Fiesta 3D is a separate project. Equal timestamps retain catalog order.
Tralala and Pug Fiesta were already linked in the first portal commit, in that
order, so their precise relative creation times are unknown.
